# CodeEvolution 🚀
## AI Multi-Agent 智能代码重构平台

> 基于 Next.js + TypeScript + Tailwind CSS + FastAPI + Python AI Agent
> 全自动「架构分析 → 智能重构 → 质量审查」一站式代码优化系统

---

## ✨ 项目简介
CodeEvolution 是一套**多 Agent 协同代码重构解决方案**。
通过三大 AI 智能体分工协作，自动分析代码坏味道、生成重构方案、优化代码结构、最终专业审查评分。

- 🧠 **Architect Agent**：代码架构分析、识别坏味道、输出标准化重构计划
- ⚙️ **Refactor Agent**：严格按照计划自动重构、精简冗余、规范命名、优化结构
- 🔍 **Review Agent**：重构质量验收、专业打分、细节点评、给出二次优化建议

全程自动化、无需人工干预，一键提升代码可读性、可维护性、工程规范性。
